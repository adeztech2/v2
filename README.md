# ADEZ XMD

A WhatsApp bot project adapted from the NOVA-XMD codebase and renamed for the ADEZ XMD brand.

## Setup

```bash
npm install
npm start
```

## Required environment variables

```bash
SESSION=
CODE=255
BOTNAME=ADEZ XMD
DATABASE_URL=
HEROKU_APP_NAME=
HEROKU_API_KEY=
```

## Project status

This repository now contains the ADEZ XMD bot scaffold, configuration, and app entry points.
